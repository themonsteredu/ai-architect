# 코벨문 설계 — 중학생 진로체험 웹앱

학생이 화면에서 벽돌을 쌓아 **코벨문(내밀어쌓기 출입구)** 을 설계하고,
검증을 통과하면 **층별 조립 도면**이 나옵니다. 그 도면을 보고 실제 미니 벽돌로 똑같이 만듭니다.

- 직업 연결: **건축가**
- 핵심 학습: 코벨링, 무게중심, 엇갈려 쌓기, 예산 안에서 설계하기

---

## 1. 실행 방법

**설치할 것이 없습니다.** 인터넷도 필요 없습니다.

- `index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
- USB에 폴더째 담아 다녀도 그대로 돌아갑니다.
- 태블릿에서는 폴더를 웹서버에 올려 두고 주소로 접속하는 편이 편합니다.

무거운 라이브러리(물리엔진 등)를 하나도 쓰지 않았습니다.
전체 용량이 사진 한 장보다 작고, 효과음도 파일이 아니라 브라우저가 직접 만들어 냅니다.

## 2. 화면 사용법 (학생)

| 순서 | 하는 일 |
|---|---|
| 1 | 시작 화면에서 **문 모양 3가지 중 하나**를 고릅니다. 기초 2단이 자동으로 깔립니다. |
| 2 | **초록색 자리**를 눌러 벽돌을 놓습니다. 초록이 아닌 곳을 누르면 "왜 안 되는지" 알려 줍니다. |
| 3 | 위로 갈수록 반 장씩 안으로 내밀어(**코벨**) 양쪽이 가운데에서 만나게 합니다. |
| 4 | **세워보기**를 누릅니다. 통과하면 완성, 실패하면 벽돌이 무너집니다. |
| 5 | 통과하면 **도면**을 열어 인쇄합니다. 그 도면대로 실물을 쌓습니다. |

- **💡 힌트** — 다음에 놓으면 좋은 자리 한 칸이 반짝입니다. 내 설계는 그대로 유지됩니다.
- **↩ 되돌리기** — 방금 한 것을 되돌립니다.
- **지우기** — 벽돌을 지웁니다. 위에 얹힌 벽돌도 같이 지워집니다. (기초는 못 지웁니다)

### 벽돌 놓는 두 가지 방향

| 방향 | 화면에서 | 실물 | 드는 장수 |
|---|---|---|---|
| **눕히기** | 가로 2칸 | 긴 면이 앞으로 (길이쌓기) | 한 겹 1장 / 두 겹 2장 |
| **90° 돌려놓기** | 가로 1칸 | 같은 벽돌을 바닥에서 돌려 짧은 끝면이 앞으로 (마구리쌓기) | 1장으로 앞뒤를 한 번에 |

**90° 돌려놓기**는 반 장짜리 별도 벽돌이 아닙니다. 같은 19×9×9mm 벽돌의 긴 19mm 방향을 앞뒤로 돌려 놓아 정면에서는 9×9mm 끝면만 보이는 것입니다. 이 방향이 있어야 줄눈을 반 장씩 엇갈리게 맞출 수 있고,
앞줄과 뒷줄을 하나로 묶어 줍니다.

### 벽 두께

- **두 겹** = 앞줄 + 뒷줄 (19mm 두께). 벽돌 2장.
- **한 겹** = 앞줄만 (9mm 두께). 벽돌 1장. 대신 **3단까지만** 쌓을 수 있습니다.
- 이미 놓인 한 겹 벽돌을 「두 겹」 상태로 누르면 **뒤에 한 겹을 더 붙입니다** (1장 추가).

## 3. 못 놓게 막는 자리 (구조 규칙)

규칙마다 왜 안 되는지 한 줄로 알려 줍니다. **이 안내문이 곧 수업 내용입니다.**

| 규칙 | 조건 | 안내문 |
|---|---|---|
| 받침 없음 | 아래에 벽돌이 없음 | 아래에 받침이 없어요 |
| 절반 미만 걸침 | 아래 벽돌에 절반 이상 얹혀야 함 | 너무 많이 튀어나왔어요 — 절반 이하로 |
| 줄눈 일직선 | 아래층 이음매 바로 위 금지 | 줄눈이 일직선이 됩니다 — 반 장 옆으로 |
| 한 겹 3단 초과 | 두께 1장인 벽은 3단까지 | 한 겹 벽은 3단까지 — 뒤에 한 겹 더 필요해요 |
| 아래보다 넓어짐 | 위층이 아래층 밖으로 나감 | 위로 갈수록 좁아져야 해요 |

여기에 두 가지를 더 넣었습니다. 위 규칙들만으로는 막을 수 없어서 꼭 필요했습니다.

| 규칙 | 왜 필요한가 | 안내문 |
|---|---|---|
| 뒷줄 받침 없음 | 한 겹 벽 위에 두 겹 벽돌을 올리면 뒷줄이 허공에 뜹니다 | 뒷줄 아래에 받침이 없어요 — 아래도 두 겹이어야 해요 |
| 문 자리 | 맨 아래 단은 받침 규칙이 없어서 문 한가운데를 막아 버릴 수 있습니다 | 여기는 문이 지나갈 자리예요 — 비워 두세요 |

**놓을 수 있는 자리는 항상 여러 군데입니다.** (자동 점검 항목에 들어 있습니다)
한 자리만 초록이면 그냥 따라 놓는 조립 키트가 되어 버리기 때문입니다.

## 4. 무게중심

중학교 1학년 수준의 **평균** 계산입니다.

> 각 단에서, 그 위에 얹혀 있는 벽돌들의 x좌표 평균을 냅니다.
> 그 평균이 아래 단의 좌우 범위를 벗어나면 넘어집니다.

- 벽돌이 1, 2, 3번 칸 → (1+2+3) ÷ 3 = 2번 → 받침(1\~3) 안 → 안 넘어짐
- 벽돌 중심이 3, 4, 5번 칸 → (3+4+5) ÷ 3 = 4번 → 받침(1\~3) 밖 → 넘어짐

화면에는 숫자 대신 **세로 점선 하나**만 보입니다. 벽돌을 놓을 때마다 좌우로 움직이고,
안전하면 초록, 위험하면 빨강입니다.

문은 기둥이 둘이므로, 붙어 있는 덩어리마다 따로 평균을 냅니다.
**양쪽 기둥에 함께 걸친 벽돌(= 아치가 닫힌 부분)은 양쪽이 같이 받치므로 어느 쪽 계산에도 넣지 않습니다.**
그래서 "코벨을 한쪽만 너무 내밀면 넘어지고, 가운데에서 만나면 버틴다"가 그대로 재현됩니다.

실패하면 원인이 된 벽돌이 빨갛게 반짝이고, 앞으로 넘어지며 떨어집니다.
위에 얹힌 벽돌들이 0.05초씩 늦게 따라 떨어집니다. (물리엔진 없이 정해진 애니메이션 0.6초)

## 5. 미적 규칙 (막지 않고 안내만)

세워보기 결과 옆에 항상 체크리스트로 보입니다.

1. **좌우 대칭** — 가운데 문 기준 양쪽이 같아야 함
2. **탑은 문보다 작게** — 탑 높이는 문 높이의 절반 이하
3. **위로 갈수록 좁게**
4. **줄눈은 엇갈리게**
5. **홀수로 세기** — 맨 윗단 덩어리는 3개나 5개

예: `왼쪽이 오른쪽보다 한 단 높습니다`

## 6. 조립 도면

「도면」 버튼(또는 세워보기 통과 후 나오는 버튼)을 누르면 열립니다. **인쇄** 버튼으로 A4에 뽑습니다.

- **1장** — 완성 모습(정면도) + 요약표 + 받침 필요한 층 목록
- **2장부터** — 1층 도면, 2층 도면, … **층마다 한 장씩**

각 층 도면에는

- **평면도**(위에서 본 그림)에 **뒷줄 / 앞줄**이 따로 그려집니다.
- 벽돌마다 **그 층 안에서의 순서 번호** ①②③… 이 붙습니다.
  전체 통번호(1\~60)는 쓰지 않습니다. 숫자가 뭉개져서 못 읽기 때문입니다.
- 아래 벽돌 밖으로 튀어나온 벽돌에는 **⚠️ 받침 블록을 괴고 쌓으세요** 가 붙습니다.
- 오른쪽에 작은 정면도가 있어 지금 몇 층을 쌓는지 한눈에 보입니다.

### 쌓는 순서 규칙

1. 아래층부터
2. 같은 층에서는 **바깥쪽부터 안쪽으로**
3. 두 겹인 곳은 **앞줄·뒷줄을 이어서 함께** (번호가 연달아 붙습니다)
4. 양쪽 기둥은 **번갈아** (왼쪽 하나, 오른쪽 하나)
5. 가운데(쐐기) 벽돌은 **맨 마지막**

## 7. 강사 설정

오른쪽 위 **⚙ 설정** → 4자리 숫자 비밀번호. **처음 비밀번호는 `1234`** 입니다.

바꿀 수 있는 값:

- 벽돌 가로 / 세로 / 높이 (mm)
- 벽돌 개수 상한
- 받침판 가로 / 세로 (mm)
- 설정 비밀번호
- **정답 도면 공개 On/Off**
- 수업 슬라이드 보기 (다음 버전)

> ⚠️ 이 비밀번호는 **수업용 잠금장치**이지 보안 장치가 아닙니다.
> 설정값은 그 태블릿의 브라우저에만 저장됩니다. 태블릿마다 따로 설정해야 합니다.

**정답 도면**을 켜면 학생 화면에 「정답 도면」 버튼이 생깁니다.
학생이 열면 화면에 `📖 정답 도면을 열어봤어요` 기록이 남습니다. (벌이 아니라 기록입니다)

## 8. 벽돌 치수가 바뀌면

재료가 바뀌어도 숫자만 바꾸면 됩니다. **치수를 정의하는 곳은 `js/config.js` 딱 한 곳뿐입니다.**
나머지 파일은 전부 거기서 가져다 씁니다.

강사 설정 화면에서 바꾸면 격자 칸 수, 화면 크기, 기초 모양, 검증, 도면, 순서가 **한꺼번에** 따라옵니다.
(자동 점검에 "벽돌을 24×12×12mm로 바꿔도 전부 정상 동작" 항목이 들어 있습니다)

### 격자 한 칸 = 벽돌 길이의 절반

요청서에는 "격자 1칸 = 벽돌 폭 0.9cm"라고 되어 있었는데, **길이의 절반(0.95cm)** 으로 잡았습니다. 이유는:

- 엇갈려 쌓기는 **반 장씩 밀어 쌓기**입니다. 반 장을 한 칸으로 잡아야 그림과 실물이 정확히 맞습니다.
- 실물 벽돌은 줄눈(모르타르) 자리 때문에 길이가 폭의 2배보다 1mm쯤 깁니다. (19 = 9 × 2 + 1)
  폭(9mm)을 한 칸으로 잡으면 벽돌 두 장이 18mm로 그려져서, 여덟 장쯤 이으면 도면이 8mm 어긋납니다.
- 벽 두께(한 겹 = 9mm)는 그대로 **벽돌 폭**을 씁니다.

**바꾸고 싶으시면** `js/config.js` 의 `get cellMm()` 한 줄만 고치면 됩니다.

### 길이 ÷ 폭 경고

`길이 ÷ 폭` 이 2에서 많이 벗어나면 경고가 뜹니다 (진행은 됩니다).

```
길이 ÷ 폭 = 2.38 — 엇갈려 쌓기가 맞지 않습니다
```

기본 벽돌(19 ÷ 9 = 2.11)은 **줄눈 여유**라서 빨간 경고 대신 안내만 나옵니다.
요청서 예시대로 2.11에도 경고를 띄우고 싶으시면 `js/config.js` 의
`RATIO_TOLERANCE: 0.25` 를 `0` 으로 바꾸세요.

## 9. 파일이 하는 일

```
index.html            화면 뼈대
css/style.css         화면 모양
css/print.css         인쇄용 (도면만 나오게)

js/config.js      ★ 치수 원본 — 벽돌 크기를 정의하는 유일한 곳
js/model.js         벽돌 데이터 구조, 격자 좌표
js/rules.js         구조 규칙 (못 놓는 자리 판정 + 안내문)
js/foundation.js    미리 깔아둘 기초 2단 (3가지)
js/balance.js       무게중심 평균 계산
js/aesthetics.js    미적 규칙 5가지 (안내만)
js/order.js         쌓는 순서 계산 + ①②③ 번호
js/validate.js      "세워보기" 판정
js/solver.js        힌트 + 정답 도면 만들기
js/sound.js         벽돌 부딪히는 효과음 (파일 없이 생성)
js/collapse.js      무너짐 연출 (물리엔진 없음)
js/blueprint.js     도면 그리기 + 인쇄
js/settings.js      강사 설정 화면
js/app.js           화면 조립, 클릭 처리

test/logic-test.js  계산 부분 자동 점검
```

## 10. 자동 점검 돌리기

개발자가 손볼 일이 생겼을 때, 고친 뒤 아래 한 줄로 확인할 수 있습니다.

```
node test/logic-test.js
```

85개 항목을 확인합니다. 마지막에 `모두 통과했습니다` 가 나오면 정상입니다.

확인하는 것:
기초가 규칙을 지키는지 · 구조 규칙이 실제로 막는지 · 무게중심 평균이 예시대로 나오는지 ·
정답 도면이 언제나 검증을 통과하는지 · 쌓는 순서가 규칙대로인지 ·
쌓는 내내 놓을 자리가 여러 군데인지 · 벽돌 치수를 바꿔도 전부 따라오는지 ·
초록색 자리에 놓으면 전체 검증이 항상 통과하는지.

## 11. 수업 흐름 참고

```
1. 자유 시도 (5분)   — 접착제 없이 "문을 만들어보세요". 대부분 실패함
2. 코벨 소개 (3분)   — 미케네 사자문, 신라 고분 사진
3. 앱에서 설계 (10분) ← 이 앱
4. 실물 조립 (20분)  — 도면 보고 벽돌 60장으로
5. 꾸미기 (10분)    — 피규어 세우기
```

기본 설정(벽돌 19×9×9mm, 받침판 150mm, 60장)에서 완성작은 대략 **50\~58장**을 씁니다.
기초 2단이 16\~20장이므로 학생이 자유롭게 쓸 수 있는 것은 **40장 안팎**입니다.

## 12. 아직 안 한 것

- **3D 회전 시점** — 요청하신 대로 나중 순서입니다. 2D 정면도만으로 수업이 굴러갑니다.
- **수업 슬라이드 보기** — 설정 화면에 자리만 만들어 두고 비활성 상태입니다.
- **디자인 다듬기** — 기능 위주로 만들었습니다. 색·글꼴·여백은 따로 손볼 예정입니다.
